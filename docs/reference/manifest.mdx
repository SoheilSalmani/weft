# Manifest reference (`weft.toml`)

A template is a directory containing `weft.toml`, an optional `presets/`
directory, and a `patches/` directory:

```
my-template/
├── weft.toml
├── presets/*.toml
└── patches/*.json
```

## `[template]`

```toml
[template]
name = "python-service"
weft-version = "0.1"
description = "A FastAPI/Flask microservice scaffold."   # optional
```

`name` and `weft-version` are required; `description` is what agents (and
`weft describe`) surface first. `name` is used in messages; `weft-version` declares
the manifest format version.

## `[[question]]`

```toml
[[question]]
id = "project_name"        # answer id; referenced by patches and expressions
kind = "string"            # string | bool | int | choice | secret
prompt = "Project name"    # optional; shown when prompting (defaults to id)
description = "Human-readable name; drives titles."   # optional, agent-facing
example = "My Shop"        # optional example value (display form)
default = "'my-project'"   # optional Starlark expression
when = "use_docker"        # optional Starlark gate; ask only if truthy
```

### Kinds

| kind     | extra fields          | value type | notes                                  |
| -------- | --------------------- | ---------- | -------------------------------------- |
| `string` | —                     | string     |                                        |
| `bool`   | —                     | bool       | Starlark default literals are `True`/`False` |
| `int`    | —                     | integer    |                                        |
| `choice` | `choices = ["a","b"]` | string     | value must be one of `choices`         |
| `secret` | `source = "env:VAR"`  | secret     | see [Secrets](../guides/secrets)       |

### Defaults and gates

`default` and `when` are **Starlark expressions**, not literals — a string
default needs quotes inside the TOML string (`default = "'api'"`). Expressions
may reference answers to *earlier* questions:

```toml
[[question]]
id = "package_name"
kind = "string"
default = "project_name.lower().replace(' ', '-')"
```

Questions are processed in declaration order: a `when` gate sees the answers
resolved so far. A question whose gate is false is skipped entirely — it is
absent from the answer set, and patches gated on it won't apply.

Questions with a `default` are auto-filled, not prompted. Only default-less
unanswered questions prompt interactively.

## `[[preset]]`

```toml
[[preset]]
name = "internal-service"
file = "presets/internal.toml"
```

A preset file is a plain TOML answer map, partial by design:

```toml
# presets/internal.toml
use_docker = true
registry = "registry.internal:5000"
```

Rules:

- Presets are applied in the order given on the command line; later presets
  override earlier ones.
- Preset keys must reference declared questions; secret questions cannot be
  set from presets (checked by `weft check`).

## `[[task]]`

```toml
[[task]]
id = "uv-sync"
inputs = ["glob:pyproject.toml", "glob:uv.lock"]
action = "uv sync"
when = "use_uv"            # optional Starlark gate
```

- `action` is a shell command (`sh -c`) run in the scaffolded project
  directory. This is the *only* place shell exists in a template.
- `inputs` declare what the task depends on:
  - `glob:PATTERN` — files in the rendered tree
  - `answer:ID` — a question's value
  - `task:ID` — another task (also creates an ordering edge)
- On `weft new`, every `when`-passing task fires, in dependency order.
- On `weft update`, a task fires only if one of its inputs changed: a glob
  matched a file that differs between the old and new renders, an answer's
  value changed, or an upstream task fired.
- A failing task aborts the run with its exit status.
